# Alur Git Sederhana

Sepakati pembagian tugas dan file bersama sebelum mulai. Setiap anggota bekerja pada branch masing-masing atau berkoordinasi langsung jika memakai satu branch. Commit perubahan kecil dengan pesan yang jelas; periksa perubahan teman sebelum digabung.

Sebelum pengumpulan, jalankan `npm run build`, uji aplikasi di browser, dan periksa `git status`. Jangan sertakan `node_modules/` atau `dist/`. Tidak perlu membuat remote atau alur pull request khusus jika tim tidak membutuhkannya.
