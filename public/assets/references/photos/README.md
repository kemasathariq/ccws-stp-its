# Foto referensi

Folder ini berisi foto yang telah disediakan tim. Pilih foto asli yang sesuai dengan objek scene dan tampilkan di dekat canvas pada halaman utama. Gunakan foto sebagai acuan bentuk dan kemiripan; foto interior dan exhibit dipakai sebagai acuan interior sederhana dan pameran.

Nama file mengikuti pola `kategori-subjek-sudut`.

| File | Isi |
|---|---|
| `eksterior-fasad-serong-kiri.jpg` | Fasad memanjang dua lantai (OPOP Training Center), atap genteng oranye, dari sudut kiri |
| `eksterior-fasad-serong-kanan.jpg` | Fasad yang sama dari sudut kanan, terlihat bangunan beratap genteng di sebelahnya |
| `eksterior-fasad-pintu-utama.png` | Pintu masuk utama, jendela berteralis, talang biru |
| `eksterior-coworking-gable-kanopi.jpg` | Sisi gable dengan tulisan CO-WORKING SPACE dan kanopi masuk |
| `eksterior-coworking-papan-nama.png` | Detail tulisan CO-WORKING SPACE dan pintu kaca |
| `eksterior-kanopi-samping.jpg` | Kanopi beton berbentuk atap pelana dari samping, di bawah pohon |
| `eksterior-kanopi-depan.jpg` | Kanopi beton dari depan dengan tempat sampah warna-warni |
| `lingkungan-pohon-parkir-motor.jpg` | Pohon besar, jalan paving, dan parkir motor beratap genteng |
| `interior-lorong-ruang-kerja.jpg` | Ruang kerja memanjang dengan exhibit kereta di ujung |
| `interior-meja-kasir-kantin.jpg` | Meja kasir/kantin dan mural kutipan |
| `interior-ruang-kerja-mural.png` | Ruang kerja dengan mural dan meja kuning |
| `interior-pameran-kereta.png` | Exhibit kereta merah-abu |

Mockup gerbong kereta di dalam CCWS memakan sekitar 3/7 panjang ruangan dan hampir selebar ruangan, dengan sedikit ruang kosong di sampingnya untuk melihat bagian depan mockup (perkiraan dari tim, bukan hasil pengukuran).
